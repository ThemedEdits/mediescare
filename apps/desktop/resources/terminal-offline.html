Cannot reach the Branch Server برانچ سرور تک رسائی نہیں ہو رہی

This counter keeps no data of its own, so it needs the Branch Server to work. Nothing was lost. یہ کاؤنٹر اپنا کوئی ڈیٹا نہیں رکھتا، اس لیے اسے چلنے کے لیے برانچ سرور چاہیے۔ کچھ بھی ضائع نہیں ہوا۔

Server:
  • Is the Branch Server PC switched on and Mediescare open on it? کیا برانچ سرور والا کمپیوٹر چالو ہے اور اس پر Mediescare کھلا ہے؟
  • Is this PC on the same network (same router or Wi-Fi)? کیا یہ کمپیوٹر اسی نیٹ ورک (وہی راؤٹر یا وائی فائی) پر ہے؟
  • Windows Firewall on the server: on that PC use the Network menu, Allow through Windows Firewall. سرور پر ونڈوز فائر وال: اس کمپیوٹر میں Network مینو سے Allow through Windows Firewall دبائیں۔
  • Did the server's address change? Use Change server and pick it again. کیا سرور کا ایڈریس بدل گیا ہے؟ Change server دبا کر دوبارہ منتخب کریں۔

Re-pair when the server was reinstalled or this counter was removed from it. You need a new pairing code from the server. جب سرور دوبارہ انسٹال ہوا ہو یا اس کاؤنٹر کو سرور سے ہٹا دیا گیا ہو تو دوبارہ جوڑیں۔ اس کے لیے سرور سے نیا پیئرنگ کوڈ چاہیے۔
