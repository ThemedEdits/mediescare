Let other counters connect دوسرے کاؤنٹرز کو جڑنے دیں
Terminals need TCP port 3210 and UDP port 3211 open on this PC. This button opens them for the local network only. Windows will ask for administrator permission. Nothing changes unless you click it. ٹرمینلز کے لیے اس کمپیوٹر پر TCP پورٹ 3210 اور UDP پورٹ 3211 کھلے ہونے چاہییں۔ یہ بٹن انہیں صرف مقامی نیٹ ورک کے لیے کھولتا ہے۔ ونڈوز ایڈمنسٹریٹر کی اجازت مانگے گا۔ آپ کے کلک کیے بغیر کچھ نہیں بدلتا۔
Or run these as administrator in Command Prompt: یا کمانڈ پرامپٹ میں ایڈمنسٹریٹر کے طور پر یہ چلائیں:

You can change this later from the Mediescare settings. Nothing needs the internet to work. آپ اسے بعد میں تبدیل کر سکتے ہیں۔ کسی چیز کو انٹرنیٹ کی ضرورت نہیں۔
